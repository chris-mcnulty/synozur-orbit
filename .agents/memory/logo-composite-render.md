# Conference graphics are deterministic brand composites

Conference anchor and session graphics must never use generative image models. Anchor graphics use approved conference media plus event/company logos; session graphics use an approved brand template or brand-color fallback plus real session data.

**Why:** Generative image output invented people and ignored configured logos, colors, and fonts, making the graphics unsafe to publish as branded event material.

**How to apply:** Keep conference graphic sources role-canonical, require configured logos, fail closed when selected assets or fonts cannot load, and render legacy AI records into deterministic replacements before changing their stored metadata or replacing posts.
