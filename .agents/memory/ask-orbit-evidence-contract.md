---
name: Ask Orbit evidence contract
description: Why the first Ask Orbit release selects excerpts instead of synthesizing factual prose
---

Ask Orbit's first release deliberately answers with selected exact excerpts, not model-authored factual paraphrases.

**Why:** A valid source ID does not prove that a generated claim follows from the source. Exact excerpt validation makes the factual answer independently verifiable without a second, paid model call or trusting an entailment judgment from the same model.

**How to apply:** Preserve the extractive boundary unless a later request explicitly expands the answer contract. A source citation proves what the stored record said, not that it is independently true; keep limitations for plans, prior AI analysis, stale evidence and bounded retrieval visible.
