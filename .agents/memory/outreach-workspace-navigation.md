name: Outreach workspace navigation
description: Keep campaign work areas separate instead of growing one long page.
---
Keep outreach campaign overview, prospects, meetings, setup and pending work in separate work areas. Do not add unrelated configuration and summary panels above the prospect directory.

**Why:** The user explicitly corrected the long-page approach after Add prospect appeared not to work because its form was far below the visible screen: “everything into a single page that becomes very tall and hard to navigate.”

**How to apply:** Put new features in the appropriate existing tab rather than adding another always-visible section. Keep prospect actions directly reachable, retain the contact-row Edit action, and preserve unsaved work when switching tabs. Meeting and draft entry points must still reach the intended person.
